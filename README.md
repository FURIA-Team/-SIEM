# MiniSIEM — документация проекта

MiniSIEM — учебный веб-прототип для регистрации и просмотра событий безопасности, формирования предупреждений по событиям высокой критичности и управления доступом пользователей.

> **Важно:** этот репозиторий на текущем этапе предназначен для документации. Исходный код приложения, ZIP-архив, локальная база данных SQLite и секреты сюда не загружаются.

- [Архитектурный обзор](docs/Architecture.md) — слои приложения, API и поток обработки событий.

## Кратко о системе

Стек: Java 25, Spring Boot 4.1.2, Spring Security, Spring Data JPA, Hibernate, SQLite, HTML, CSS и JavaScript.

Основные возможности:
- регистрация и вход, роли ADMIN и USER;
- приём событий через REST API;
- автоматическое создание предупреждений для событий HIGH и CRITICAL;
- поиск, фильтрация, пагинация и экспорт событий в CSV;
- управление статусами предупреждений;
- административное управление пользователями и настройками;
- журналирование предусмотренных действий.

## Важные ограничения

MiniSIEM — учебный прототип, а не промышленная SIEM-платформа. События поступают через API; агентский сбор телеметрии, сложная корреляция, автоматическое удаление данных по retentionDays и промышленная масштабируемость в текущей версии не подтверждены.
