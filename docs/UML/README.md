# MiniSIEM UML диаграммалары

Диаграммалар жобаның құрылымы мен нақты REST маршруттарына сүйене отырып дайындалған. Диаграммалардың бастапқы файлдары PlantUML (`.puml`) пішімінде сақталады.

## Дәлдікке қатысты ескертпелер
- `SecurityAlert.eventId` — бірегей идентификатор өрісі. Ол JPA ORM байланысы болып саналмайды.
- Диаграммаларда барлық техникалық класс әдістері емес, логикалық тәуелділіктер мен шақырулар көрсетілген.
- Орналастыру диаграммасы әдеттегі жергілікті іске қосуды көрсетеді, өндірістік ақауға төзімді инфрақұрылымды емес.
- Ескерту күйлері: OPEN, INVESTIGATING, RESOLVED.
- Ескерту HIGH және CRITICAL деңгейлері үшін жасалады.
