# UML-диаграммы MiniSIEM

Диаграммы подготовлены по структуре проекта и фактическим REST-маршрутам. Исходники диаграмм хранятся в формате PlantUML (`.puml`).

2. [Диаграмма компонентов](component.puml)

4. [Последовательность аутентификации](sequence-auth.puml)
5. [Последовательность обработки события](sequence-event-processing.puml)
6. [Диаграмма активности правила предупреждения](activity-alert-rule.puml)
7. [Диаграмма развёртывания](deployment.puml)
8. [Логическая ER-диаграмма](er-diagram.puml)
9. [Диаграмма состояний предупреждения](alert-state.puml)

## Примечания к точности
- `SecurityAlert.eventId` — уникальное поле-идентификатор. Оно не является ORM-связью JPA.
- На диаграммах показаны логические зависимости и вызовы, а не все технические методы классов.
- Диаграмма развёртывания отражает типичный локальный запуск, а не отказоустойчивую промышленную инфраструктуру.
- Статусы предупреждения: OPEN, INVESTIGATING, RESOLVED.
- Создание предупреждения описано для уровней HIGH и CRITICAL.
