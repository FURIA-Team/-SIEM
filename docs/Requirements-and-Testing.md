# MiniSIEM жүйесінің талаптары және тестілеу

## Функционалдық талаптар

| ID | Талап | Қолжетімділік |
|---|---|---|
| FR-01 | Пайдаланушыны тіркеу | Ашық маршрут |
| FR-02 | Жүйеге кіру және шығу | Ашық маршрут / ағымдағы сессия |
| FR-03 | Ағымдағы пайдаланушыны қарау | Аутентификациядан өткен пайдаланушы |
| FR-04 | Бақылау панелін қарау | USER, ADMIN |
| FR-05 | Қауіпсіздік оқиғасын жасау | USER, ADMIN |
| FR-06 | Оқиғаларды іздеу, сүзу және беттеу | USER, ADMIN |
| FR-07 | Оқиғаларды CSV форматына экспорттау | USER, ADMIN |
| FR-08 | Ескертулерді қарау және сүзу | USER, ADMIN |
| FR-09 | Ескерту күйін өзгерту | USER, ADMIN |
| FR-10 | Жүйелік журналдарды қарау | USER, ADMIN |
| FR-11 | Пайдаланушыларды қарау, жасау және жою | ADMIN |
| FR-12 | Жүйе баптауларын қарау және өзгерту | ADMIN |
| FR-13 | HIGH/CRITICAL оқиғасы үшін ескерту жасау | Оқиғаны өңдеу кезінде автоматты түрде |

## Функционалдық емес талаптар
- Парольдер BCrypt хештері түрінде сақталады.
- Деректерді өзгертетін сұраныстар CSRF қорғанысын ескереді.
- Әкімшілік операциялар сервер жағында тексеріледі.
- Деректер тұрақты сақтау орнында сақталады.
- Код қабаттарға бөлінген.
- API кіріс деректерін тексеріп, құрылымдалған қателерді қайтарады.

## Автоматтандырылған тесттер
Бастапқы жобада бес тест класы бар: `MinisiemApplicationTests`, `AuthControllerTests`, `AdminBootstrapControllerTests`, `SecurityOperationsControllerTests`, `SecurityOperationsAdditionalTests`.

Бұрын тіркелген жергілікті іске қосу нәтижесінде 23 тест сәтті орындалғаны, қате мен өткізіп жіберілген тест болмағаны хабарланған. Соңғы тапсыру алдында JDK 25 орнатылған мақсатты компьютерде тесттерді қайта орындап, іске қосу журналын сақтау қажет.

## Расталмаған тексерулер
Қолда бар нәтижелер браузердегі толық E2E тестілеудің, жүктемелік сынақтардың, қауіпсіздік аудитінің немесе ену тестілеуінің толық жүргізілгенін растамайды.
