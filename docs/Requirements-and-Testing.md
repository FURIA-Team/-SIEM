# Требования и тестирование MiniSIEM

## Функциональные требования

| ID | Требование | Доступ |
|---|---|---|
| FR-01 | Регистрация пользователя | Публичный маршрут |
| FR-02 | Вход и выход | Публичный маршрут / текущая сессия |
| FR-03 | Просмотр текущего пользователя | Аутентифицированный пользователь |
| FR-04 | Просмотр панели мониторинга | USER, ADMIN |
| FR-05 | Создание события безопасности | USER, ADMIN |
| FR-06 | Поиск, фильтрация и пагинация событий | USER, ADMIN |
| FR-07 | Экспорт событий в CSV | USER, ADMIN |
| FR-08 | Просмотр и фильтрация предупреждений | USER, ADMIN |
| FR-09 | Изменение статуса предупреждения | USER, ADMIN |
| FR-10 | Просмотр системных журналов | USER, ADMIN |
| FR-11 | Просмотр, создание и удаление пользователей | ADMIN |
| FR-12 | Просмотр и изменение системных настроек | ADMIN |
| FR-13 | Создание предупреждения для HIGH/CRITICAL | Автоматически при обработке события |

## Нефункциональные требования
- Пароли хранятся в виде BCrypt-хешей.
- Изменяющие запросы учитывают CSRF-защиту.
- Административные операции проверяются сервером.
- Данные сохраняются в постоянном хранилище.
- Код разделён на слои.
- API валидирует входные данные и возвращает структурированные ошибки.

## Основные сценарии тестирования

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-01 | Регистрация с корректными данными | Пользователь создан |
| TC-02 | Повторный username/email | Запрос отклонён |
| TC-03 | Вход с корректными данными | Сессия создана |
| TC-04 | Защищённый API без входа | HTTP 401 |
| TC-05 | USER обращается к admin API | HTTP 403 |
| TC-06 | Изменяющий запрос без CSRF | Запрос блокируется |
| TC-07 | Создание события HIGH | Событие и предупреждение сохранены |
| TC-08 | Создание события CRITICAL | Создано предупреждение |
| TC-09 | Создание MEDIUM или LOW | Автоматическое предупреждение не создаётся |
| TC-10 | Изменение статуса предупреждения | Новый статус сохранён |
| TC-11 | Поиск и фильтрация событий | Выбраны соответствующие записи |
| TC-12 | Экспорт событий | Возвращён CSV |
| TC-13 | Изменение настроек администратором | Настройки сохранены, действие отражено в журнале |

## Автоматизированные тесты
В исходном проекте присутствуют пять тестовых классов: `MinisiemApplicationTests`, `AuthControllerTests`, `AdminBootstrapControllerTests`, `SecurityOperationsControllerTests`, `SecurityOperationsAdditionalTests`.

В ранее зафиксированном локальном прогоне сообщалось о 23 успешных тестах, без ошибок и пропусков. Перед финальной сдачей результат следует повторить на целевой машине с JDK 25 и сохранить лог.

## Не заявленные проверки
Имеющиеся результаты не подтверждают полноценные браузерные E2E-тесты, нагрузочные испытания, аудит безопасности или тестирование на проникновение.
